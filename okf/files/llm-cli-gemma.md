A gate that replays reference token ids and writes this engine's hidden
states beside them, a tokenizer round trip, and a plain greedy decode. The
gate is the point: free-running text proves nothing, and every bug this
architecture hides shows as a diverging hidden state long before a bad word.
See `gemma4-port`.
